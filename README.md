# 智训引擎企业赛 CPU Harness

使用 contest-harness-sdk 1.0.5。平台通过 `/app/harness.py describe|train|predict` 进入镜像。A 对气体分类，B 和 C 分别预测轴承与发动机剩余寿命。每轮从宿主指定的工业模型继续训练，继承归一化参数、MLP 权重、Adam 状态和累计步数。

Qwen 经宿主网关读取本轮合同、公开测量、各轮历史趋势以及上一次实际实验程序，提出可执行的数值训练方案。CPU 工作者验证程序、训练父模型并保存候选。宿主测量候选后，Qwen 对照本轮父模型和候选的结果，选择下一轮起点。SDK 保存原生状态并以真实回执结束本轮。

A 在稳态通道上学习乙醇与乙醛的差异，以两类训练损失决定停止辅助更新的时刻。B 比较总体误差和短寿命四分位误差，从父模型连续执行阻尼 Gauss–Newton 与 Adam。同一父模型、阶段、训练和验证数据上的上一候选若总体 RMSE 升高且实际保留父模型，下一轮直接用 Qwen 的 Adam 程序更新；一次直接 Adam 测试后恢复曲率加 Adam。C 按当轮公开训练输入识别工况。三个设置量的标准差分别除以父模型对应尺度，三项均小于 0.1 时直接执行提案 Adam；其余工况先进行输入预调和带四次惩罚的原网络拟合，再执行提案 Adam。对历史工况保留最多 128 条公开训练样本，用于复核工况等权的均方误差。选模同时看 RMSE 与非对称寿命惩罚。各任务的输出都可由官方原始预测程序和选中检查点复现。

初始宽工况连续出现时，C 记录父网络在当前公开训练输入的预测，约束其上十分位继续升高与下十分位继续降低。两侧分别使用 10 和 13 个循环的尺度。见到另一训练投影后结束这项约束。

C 在连续两轮使用同一训练投影、父权重相同且上一候选仅因已见数据的误差上升而保留父模型时，用每个旧投影最多 128 条训练输入保持父模型预测。拟合样本和选模样本按索引分开。每个旧投影等权参与，预测仍由同一工业网络完成。

逐条预测复用已验证的不可变模型和特征路径。模型凭据由宿主持有。构建架构为 Linux/amd64，运行用户 UID 10001，数值库采用单线程。运行入口和资源实测见本版本随附的验收记录。
