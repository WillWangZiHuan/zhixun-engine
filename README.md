# 智训引擎 · 同条件实验与父模型续训

SDK 1.0.4 接收平台提供的父检查点、训练数据和当期公开验证集。Qwen/Qwen3.8-27B 经宿主接口给出训练程序和选模决定。A 首轮沿用原训练流程。当上一轮回滚且当前父模型仍是被保留的父模型时，在当轮公开数据上用固定 Adam 程序实测带气体辅助更新与仅 Adam 两条分支。一旦触发，后续沿宿主选定的模型继续保留两种选项，并重新测量。Qwen 读取两组 Macro-F1、准确率和当期父模型指标，选择更新模式并给出训练程序。候选实测后由 Qwen 再决定保留父模型或候选。B、C 在同一父网络上构造几种仅使用训练集的权重更新，公开验证集用于对照。模型结合本轮对照和历史成对误差，指定更新方式、Adam 程序和步数预算，再依据实测结果选父模型或候选。

B 可选择原网络的阻尼二阶更新，或对原输出层做长寿命加权、残差加权更新。C 可比较原协方差预条件更新、非对称尾部目标和两者的插值，并行观察 RMSE 与 NASA 惩罚。同父检查点、相同训练和验证数据、同阶段下重复曾被否决的数值程序时，控制器将两部分的更新幅度减半，记录实际幅度和指标；父模型或数据改变时重新开始对照。所有参数更新均继承官方权重、缩放和 Adam 状态。预测只加载实际选定的官方格式检查点。

C 在上一轮从同一父模型续训、降低 RMSE 却加重 NASA 惩罚并回滚时，追加两种当轮可测的实验。两种实验分别从全步和半步续训方向出发，对输出偏置做一次基于训练误差的非对称损失 Newton 更新，以本次训练预测的均方根变化限制位移。Qwen 根据当前公开指标选择，并在实际训练后复核两个指标。
