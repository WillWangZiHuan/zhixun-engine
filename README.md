# 智训引擎 · 官方父模型续训候选

从已完成正式评测的镜像 11 派生。SDK 1.0.4 负责 describe、train、predict。每轮向宿主请求 Qwen 的训练提案和选模决策，生成的数值程序更新平台指定父模型的权重和 Adam 状态。训练与预测均使用官方 baselines.model.Model 文件格式和前向计算。

A 在原网络内学习乙醇与乙醛的稳态响应差异，并约束其他训练类别的输出接近父模型。模型可提出遮蔽部分训练特征的对照，B 在父网络四组已有权重上计算加权 Huber 残差的阻尼 Gauss-Newton 更新，再使用继承的 Adam 状态执行当轮数值提案，C 先用训练输入协方差调整父网络梯度方向并更新两遍，再按提案续训。C 依据当轮 RMSE 和非对称寿命惩罚选择产物。训练批次、学习率、样本权重及损失均记录在提案中。预测只读取所选官方格式检查点。

选模回复由 Qwen 返回 parent 或 candidate 及理由，harness 绑定本轮真实回执 ID 并交给官方 SDK 完成提交。
