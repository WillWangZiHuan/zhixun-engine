# 智训引擎 SDK 1.0.4 候选版

以官方 SDK 的 describe、train 和 predict 为入口。每轮从宿主指定的父检查点续训，读真实历史，用宿主模型回执提出实验，再依据平台测量选择模型。提案与选择均关闭思考，单次输出上限为 min(16384, 当轮授权值)。

已收到回执且本地验证拒绝时，模型可依据错误在同一阶段修订至多两次。每次续训使用同一父检查点和独立目录。成功的候选只提交一次，结束时引用本轮所有模型调用。宿主 RPC 结果未知时结束该轮，保留 SDK 错误码。分类得分并列时沿用模型 argmax 的类别顺序，按协议产生唯一最高分。

Dockerfile 使用项目既有 Linux/amd64 基础镜像，基础归档和官方 SDK 的摘要见 PROVENANCE.json。
